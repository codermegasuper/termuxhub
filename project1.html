🚀 Проект 1 — Telegram бот

Здесь ты создашь своего первого бота.

📦 Установка библиотеки:

pip install pyTelegramBotAPI

💡 Идея:

Бот отвечает на сообщения и выполняет команды.

🔥 Пример:

import telebot

bot = telebot.TeleBot("TOKEN")

@bot.message_handler(func=lambda m: True)
def echo(m):
    bot.reply_to(m, m.text)

bot.polling()
